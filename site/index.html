FAQ

Frequently asked questions

What is InstaLume?

InstaLume is an independently customized Android client project — a rebrand of the InstaZen mod by SpoilerTech. It is built and released by Umaiz Sufiyan, and it is not an official product.

Is it an official Instagram app?

No. InstaLume is unofficial and is not affiliated with, endorsed by or connected to Meta or Instagram. Instagram is a trademark of its respective owner.

How do I download the APK?

Use the Download button on this page, which points at the latest verified asset on GitHub Releases. Install it on an Android device and allow installation from unknown sources when prompted.

Which Android versions and architectures are supported?

Android 9+ (API 28 and above) on arm64-v8a.

How can I verify the APK?

Compare the SHA-256 published on the release against the file you downloaded, and verify the signature with apksigner verify. Every release is signed with the same stable release key.

Why might an update fail to install?

Android will not upgrade across different signing keys, so a device running the original InstaZen build (signed with a different key) must uninstall it first. The package name stays com.instazen.android.

Does Instagram login currently work?

No. Login is a documented limitation: the base client is outdated and rejected server-side. No client version is spoofed, no authentication path is bypassed and no login result is faked. See the README for the verified details.

How can I report a bug?

Open an issue on the GitHub repository, or report a security issue privately using the contact in the security policy.
